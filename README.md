# EduBot


Проект представляет собой автономного AI-ассистента, интегрированного во внутренний мессенджер образовательной платформы (на базе Moodle). Бот использует раздел «Избранное» (чат с самим собой) как интерфейс для взаимодействия с пользователем: читает входящие вопросы, обрабатывает их через LLM по заранее заданной базе знаний и отправляет ответы обратно в чат.

Так как платформа не предоставляет открытого API для разработчиков, взаимодействие реализовано через реверс-инжиниринг приватных AJAX-эндпоинтов Moodle, программную эмуляцию сессий и парсинг скрытых токенов безопасности.


## Ключевые особенности
- Программная авторизация: Обход механизмов защиты Moodle путем извлечения logintoken (CSRF) из HTML-страницы логина и сохранения аутентификационных Cookie (MoodleSession, MOODLEID1_).
- Reverse Engineering Moodle API: Использование недокументированных методов (например, core_message_get_self_conversation и core_message_get_conversation_messages) для взаимодействия с чатом.
- Интеграция с LLM: Обработка вопросов с помощью API OpenRouter (модель Gemini / Grok) с инжекцией контекстной базы знаний.
- Устойчивый Polling: Механизм регулярного опроса сервера на наличие новых сообщений с фильтрацией уже прочитанных и обработкой сетевых ошибок.
- GUI-клиент: Минималистичный графический интерфейс на customtkinter для удобного ввода учетных данных и запуска бота в фоновом потоке.


## Стек технологий

- Язык: Python 3
- Сетевое взаимодействие: requests
- Парсинг: BeautifulSoup4, re
- GUI: customtkinter 
- AI: OpenRouter API (LLM)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/g3kkkO/EduBot.git
cd EduBot
```

2. Установите зависимости
```bash
uv sync
```
3. Настройте переменные окружения.
Создайте файл .env в корневой папке проекта и добавьте туда ваш API-ключ от OpenRouter:
```
KEY=ваш_api_ключ_openrouter
```
4. Запустите приложение:
```bash
uv run gui.py
```

Примечание: Проект создан исключительно в образовательных целях для демонстрации навыков сетевого взаимодействия, реверс-инжиниринга веб-приложений и интеграции API.
